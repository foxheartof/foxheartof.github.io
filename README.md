# FoxHeart · Meet & Greet — MiYu Erocon

Sitio estático de una sola pantalla para **https://foxheartof.github.io/**.
Diseñado como un **hero / cartel digital sin scroll**, optimizado para tráfico desde redes sociales y Meta Ads.

## Publicar en GitHub Pages

1. Descomprime el ZIP.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio `foxheartof.github.io` en la rama `main`.
3. Verifica en **Settings → Pages** que esté configurado **Deploy from a branch → main → /(root)**.
4. Abre `https://foxheartof.github.io/`.

No requiere dependencias, build, npm, base de datos ni JavaScript.

## Archivos principales

- `index.html`: contenido y estructura.
- `styles.css`: diseño responsive.
- `assets/logo.png`: logo oficial de FoxHeart.
- `assets/hero-main.jpg`: imagen oficial principal.
- `assets/favicon.svg`: favicon.
